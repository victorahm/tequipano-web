# Security Policy

## Supported versions

Security fixes are applied to the latest `master` branch.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting on this repository: open the
**Security** tab and choose **Report a vulnerability**. You can also contact
the maintainer privately through GitHub at [@victorahm](https://github.com/victorahm).

Please include:

- a description of the issue and its impact,
- steps to reproduce (a minimal example is ideal),
- the affected version/commit, if known.

You should receive an acknowledgement within a few days. Once a fix is
available, it will be released publicly with appropriate credit.
